# ورشة APK

تطبيق أندرويد: ضع ملف APK/APKS، اكتب أمرًا بالعربية («غيّر الأيقونة»، «احذف صلاحية الكاميرا»…)،
يفهمه Claude، يعرض لك المعاينة، ثم يعدّل الملف ويوقّعه ويعطيك نسخة قابلة للتثبيت.

## البناء (بدون تثبيت أي شيء)
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. تبويب Actions ← "Build APK" ← Run workflow.
3. حمّل artifact باسم `app-debug` وثبّت الـ APK.

## الاستعمال
- ⚙️ ← ضع مفتاح Claude API.
- «اختيار APK» ← اكتب أمرك ← راجع المعاينة ← «تنفيذ» ← «النسخ» للتثبيت أو الحفظ.

## ملاحظات
- التعديل على الموارد وAndroidManifest فقط (لا تعديل كود Java/smali).
- النسخة المعدّلة تُوقَّع بمفتاح جديد خاص بالتطبيق، فيجب إزالة النسخة الأصلية قبل تثبيتها (تضيع بياناتها).
- المفتاح محفوظ داخل بيانات التطبيق: إن حذفت «ورشة APK» ضاع، ولن تُثبَّت نسخ جديدة فوق القديمة.
- يتطلب أندرويد 10 فما فوق.
